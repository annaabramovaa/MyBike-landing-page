# MyBike Landing Page
This is a responsive website based on a design from Figma. It represents a page dedicated to bicycles, featuring a modern and stylish interface
## Project Description
The MyBike Landing Page is a single-page website created to showcase the MyBike electric bike brand. It provides visitors with essential information about the brand, a comparison of available bike models, key technical features, and contact information. The website combines a clean, modern design with a user-friendly layout, allowing visitors to easily explore the available information and find what they need.
# Features
- **Responsive Design**: The page adapts seamlessly to different screen sizes, providing a consistent experience on both desktop and mobile devices.
- **Interactive Elements**: JavaScript enhances the user experience with interactive features, such as revealing the phone number when hovering over the top bar.
- **Modern Design**: Follows contemporary web design principles to create a clean, attractive, and engaging interface.
- **Accessibility**: Designed with accessibility in mind to ensure the content is easy to use and navigate for a wide range of users.
## Technologies Used
This project was built using the following technologies:
- **HTML5:** Used to structure the page content with semantic and accessible markup.
- **CSS3:** Used for styling, layout, and responsive design across different screen sizes.
- **Sass:** A CSS preprocessor that improves code organization and maintainability through variables, nesting, and mixins.
- **JavaScript:** Used to implement interactive elements and dynamic functionality with modern JavaScript features.
- **Node.js:** Used as the JavaScript runtime environment for the project.
- **NPM:** Used to manage dependencies and project scripts.
- **Parcel:** A fast, zero-configuration bundler used to build and optimize the project.
- **Git:** Used for version control and tracking changes throughout development.
- **GitHub:** Used to host the repository and manage the project code.

- **NPM** (version 6.x or newer): The Node.js package manager, used for managing project dependencies.

## Installation and Setup

To install the project and run it locally, follow these steps:

1. Clone the repository:

    ```
    git clone https://annaabramovaa.github.io/MyBike-landing-page/
    ```

2. Navigate to the project directory:

    ```
    cd MyBike-landing-page
    ```

3. Install dependencies:

    ```
    npm install
    ```

4. Start the local development server:

    ```
    npm start
    ```
5. Open http://localhost:8080/ in your browser to view the website.
